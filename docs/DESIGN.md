# Design / UX — MapleCheck v0.1

## Principle
Glanceable. The badge is the product; the popup is the explanation.

## Badge (toolbar icon overlay)
| Verdict | Text | Colour | Meaning |
|---|---|---|---|
| CA | province code (`QC`, `ON`, …) | red `#D52B1E` | Canadian-controlled, HQ in that province |
| US | `US` | amber `#F59E0B` | American-controlled — the warning |
| OTHER | ISO code (`SE`, `FR`) | grey `#6B7280` | Neutral |
| UNKNOWN | `?` | light grey | Not in data, Wikidata miss |
| (no badge) | — | — | Non-http page, new tab, settings |
Tooltip (action title) repeats the verdict in words. Canadian brand with foreign parent → verdict follows the parent (e.g. Rona → `US`), popup explains.

## Popup (320px card)
1. Header: emoji + verdict line — `🍁 Canadian — Québec` / `⚠️ American company` / `🌐 Sweden` / `❓ Unknown`. Header background tinted with badge colour.
2. Company name · city, province.
3. If foreign-owned Canadian brand: `Owned by Sycamore Partners (US)` in amber.
4. Notes (one line) · Sources (links) · data origin tag (`seed` / `wikidata` / `manual`).
5. Actions: **Set manually** (inline: country select; province select when CA; save → override synced) · **Wrong? Suggest a fix** (prefilled GitHub issue).
6. Footer: link to Options.
Dark mode via `prefers-color-scheme`. System font. No images beyond the icon.

## Options page
Wikidata toggle (default on) · US banner toggle (stored, inactive, labelled "coming soon") · Clear cache · Overrides table with delete · Data version and counts.

## Icon
Red rounded square with white maple leaf (generated by `scripts/make-icons.mjs`). Badge overlays bottom-right per browser convention.

## Copy (en / fr-CA)
All strings in `src/lib/i18n.js`. French uses Québec conventions (« Entreprise canadienne — Québec », « Entreprise américaine », « Inconnu »).
